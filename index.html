Link Sanitizer

Paste a link. Get back only what's needed to open it, without the tracking parameters, redirect wrappers and share IDs.

    Try:

    Chrome extension

    Cleans links as you copy them: Ctrl+C, a site's own "Copy link" or "Share" button, or right-click → Copy clean link. Alt+Shift+L cleans whatever is already on the clipboard.

    Download extension
    1. Unzip it somewhere permanent.
    2. Open chrome://extensions and switch on Developer mode.
    3. Click Load unpacked and pick the unzipped folder.

    Command line

    One Python file with no dependencies. On Wayland, linkclean -c cleans the clipboard in place.

    curl -Lo ~/.local/bin/linkclean \
  https://raw.githubusercontent.com/YajatGhule/link-sanitizer/main/linkclean.py
chmod +x ~/.local/bin/linkclean
linkclean 'https://…'

    What it does

    Unwraps redirects
    Google, Facebook, Instagram, Messenger, YouTube, DuckDuckGo, Reddit, Steam, LinkedIn, Slack, Bing
    Removes trackers
    utm_*, fbclid, gclid, si, igsh, mc_cid, _hsenc, srsltid and about 70 more
    Shortens known sites
    Amazon → /dp/ASIN, eBay → /itm/ID, YouTube → ?v=ID, X / Instagram / Reddit / TikTok / Spotify → path only
    Keeps what matters
    On other sites, parameters like ?id=42 stay. Strict mode drops everything after the path.

    Runs entirely in your browser. Nothing you paste leaves this page.
